# ANTIGRAVITY — AI Fashion Stylist Extension

ANTIGRAVITY is an AI-powered Chrome extension that helps users discover complete outfit combinations using natural language prompts and fashion inspiration images.

The extension acts like a virtual AI stylist by generating:
- Matching outfit ideas
- Fashion aesthetics
- Color palettes
- Accessories
- Styling recommendations

Instead of endlessly scrolling through shopping websites, users can instantly receive AI-curated styling suggestions.

---

# Features

## AI Outfit Generation
Generate complete outfit combinations using simple prompts.

Examples:
- Korean pastel cafe outfit
- Luxury office styling
- Wedding saree styling
- Streetwear fashion

---

## Fashion Style Detection
The AI automatically detects fashion aesthetics like:
- Korean Romantic Aesthetic
- Luxury Corporate Minimalism
- Gen-Z Streetwear
- Scandinavian Casual

---

## Image-Based Inspiration
Users can upload outfit inspiration images to guide AI styling suggestions.

---

## AI Confidence Meter
Displays AI styling confidence visually using animated progress bars.

---

## Smart Shopping Suggestions
Generate fashion-oriented shopping searches directly from outfit recommendations.

---

## Collapsible AI Sidebar
Modern floating sidebar UI inspired by tools like Copilot and Grammarly.

# How To Use

1. Install the Chrome extension
2. Open shopping websites
3. Upload inspiration image or type outfit idea
4. Click "Generate Outfit"
5. Explore AI-generated fashion suggestions
